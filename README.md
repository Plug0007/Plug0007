# 💫 About Me

I'm a Computer Science student passionate about **Cybersecurity, Ethical Hacking, Penetration Testing, and Software Engineering**. I enjoy exploring network security, vulnerability assessment, secure systems, and building technology that solves real-world problems.

I'm also interested in **AI/ML, Cloud Computing, Android Development, and IoT**, with a focus on learning by building and experimenting.

### 🚀 Key Projects

- **CyberDisha** – Cyber Intern Management System designed to streamline cybersecurity internship management, intern onboarding, task allocation, progress tracking, and administration.
- **AAYA-MESH** – LoRa-based mesh telemetry platform for distributed environmental monitoring.
- **Signet** – SMS OTP gateway platform designed to connect Android-based SMS gateways with developer APIs.
- **LOMI** – Experimental local AI application focused on on-device model inference.
