## 💫 About Me

I'm a Computer Science student passionate about **Cybersecurity, Ethical Hacking, Penetration Testing, and Software Engineering**. I enjoy exploring network security, vulnerability assessment, secure systems, and building technology that solves real-world problems.

I'm also interested in **AI/ML, Cloud Computing, Android Development, and IoT**, with a focus on learning by building and experimenting.
